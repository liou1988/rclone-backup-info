I盘备份首页隐私政策
更新日期：2026年11月7日

隐私政策

本政策适用于“I盘备份”个人工具。该工具仅由所有者本人使用，不面向其他用户提供服务。

访问的数据与用途

本地 rclone 在获得本人 Google 授权后，访问 Google Drive 的目录、文件名称、标识符、大小、修改时间等信息，并按备份需要读取、创建或更新文件内容。这些数据仅用于定位备份目录、比较文件及完成本人指定的备份，不用于广告、画像、出售或训练通用人工智能模型。

传输、保存与共享

备份内容由本机直接发送至本人授权的 Google Drive，不经过本网站。OAuth 凭据保存在本机 rclone 配置中，本地运行日志可能包含文件路径和操作结果；本网站不接收这些凭据、日志或备份文件。若本机使用代理联网，网络请求将经过本人配置的代理，其数据处理取决于所选服务。

工具不主动向其他第三方出售或共享 Google 用户数据。云端文件由 Google Drive 保存，适用 Google 的相关条款及隐私政策。Google API 数据的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、删除与撤销

云端备份保留至本人在 Google Drive 中删除。本机配置及日志保留至本人删除。停止任务不会自动删除已有备份；撤销 Google 授权会阻止后续 API 访问，但不会删除已有云端文件。

网站访问与联系

本静态网站未加入统计脚本、广告、表单或应用自行设置的追踪 Cookie。托管平台可能按其政策处理必要的访问日志。本工具的所有者也是唯一使用者；如有数据或授权问题，由本人在本机配置及 Google 账号设置中处理。
